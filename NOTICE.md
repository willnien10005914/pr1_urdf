# Upstream description snapshot

`assets/rp1_description` is a checkout of [Roboparty/rp1_description](https://github.com/Roboparty/rp1_description) at the commit recorded in `assets/rp1_description/UPSTREAM_COMMIT.txt`.

That repository did not contain a LICENSE file at the snapshot. The RP1 overview repository is GPL-3.0 and says each sub-repository states its own license. These URDF, MJCF, and STL files are included so this studio can review the published model. They are not original work of this repository.

`public/vendor/three` and `public/vendor/urdf-loader` keep their own license files. Three.js and the URDF loader are Apache-2.0.

SMPL and SMPL-X weights are not included. They stay in the local GVHMR cache after you accept the upstream body-model license.
